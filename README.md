# Настройка скидки — второй прототип

Товары с минимальной скидкой находятся над слайдером. Пояснение под полем постоянно видно и меняется вместе с суммой. При скидке от 250 ₽ товары скрываются, пояснение описывает общую скидку.

Диапазон 50–1500 ₽, шаг 1 ₽, линейная шкала, старт 775 ₽ — середина диапазона. Фон #606060. Доступны ручной ввод и экранная цифровая клавиатура. Данные демонстрационные.

Для локального запуска: `python3 -m http.server 8794`, затем открыть http://localhost:8794/. Сборщик не требуется.

В адресах JS/CSS указан хеш содержимого, чтобы обновления не подменялись старыми файлами из кеша браузера. index.html создаётся из исходного шаблона в рабочем проекте; версии ресурсов обновляются автоматически при подготовке публикации.
